# D13 만나보기 모드 검증

## 개인정보 경계

- 상호 수락 전: 30초 TTL의 무작위 `candidateRef`와 거리 밴드만 반환
- 상호 수락 전 비공개: 세션 ID, 사용자 ID, 정확 좌표, 정확 거리, 반려견 프로필
- 상호 수락 후: 상대의 최신 Redis 위치와 허용된 반려견 프로필만 반환
- 거절·취소·만료·차단·모드 OFF·일시정지·산책 종료 시 공유 종료
- 감사 로그에는 상태 전이만 저장하고 좌표를 저장하지 않음

## 상태 흐름

`PENDING → ACCEPTED | REJECTED | CANCELLED | EXPIRED`

`ACCEPTED → ENDED`

동일한 두 세션 사이에는 `PENDING` 또는 `ACCEPTED` 요청을 하나만 허용한다. 요청은 2분 후
서버 스케줄러가 만료시키며 WebSocket 개인 큐로 상태를 알린다. 차단 관계는 Redis 후보와
요청 생성 양쪽에서 제외한다.

## 실행

```powershell
.\performance\Test-D13MeetFlow.ps1
```

스크립트는 신규 계정 두 개와 만나보기 산책을 생성하고 비노출→요청→수락→제한 공개→차단을
검증한 뒤 산책 세션을 종료한다.
