# D17 실기기 검증 체크리스트

## 1. 실행 준비

- [ ] PostgreSQL과 Redis 컨테이너가 `UP`인지 확인한다.
- [ ] `GET /actuator/health`의 전체 상태와 `db`, `redis`가 모두 `UP`인지 확인한다.
- [ ] 백엔드를 8080 포트로 실행한다.
- [ ] 프론트엔드를 `npm run dev -- --host 0.0.0.0`으로 실행한다.
- [ ] 휴대폰과 개발 PC를 같은 Wi-Fi에 연결하고 `http://<PC IPv4>:5173`으로 접속한다.
- [ ] 테스트 전 브라우저의 위치 권한을 허용하고 절전·데이터 절약 모드를 기록한다.
- [ ] 테스트 계정, 반려견 2마리, 대표 코스 1개, 공개/비공개 그룹 각 1개를 준비한다.

## 2. 권장 기기 조합

| 구분 | 최소 대상 | 확인 브라우저 |
|---|---|---|
| Android | 실제 Android 1대 | Chrome 최신 |
| iOS | 실제 iPhone 1대 | Safari 최신 |
| 데스크톱 회귀 | Windows PC | Chrome 최신 |

각 기기에서 OS 버전, 브라우저 버전, 네트워크, 테스트 시각을 결과표에 남긴다.

## 3. 인증·온보딩·마이

- [ ] 신규 가입 후 반려견 등록 온보딩으로 이동한다.
- [ ] 반려견 사진, 생년월일, 성별, 중성화 여부, 특징 태그, 성격, 한 줄 소개가 저장된다.
- [ ] 로그인 후 대표 코스/기록 유무에 따라 일반 홈 또는 `no-course` 홈으로 올바르게 이동한다.
- [ ] 새로고침 후에도 refresh cookie로 로그인 상태가 복구된다.
- [ ] 이메일은 수정할 수 없고 닉네임은 중복 확인 후에만 저장된다.
- [ ] 반려견 추가·수정·소프트 삭제와 기본 산책 친구 단일 선택이 정상이다.
- [ ] 실제 업로드 사진과 기본 프로필 전환이 새로고침 후에도 유지된다.

## 4. 코스·지도

- [ ] 추천 코스 목록·상세·비교가 실제 API 데이터로 표시된다.
- [ ] 시간대 변경 시 구간 온도와 쾌적도 색상이 일치한다.
- [ ] 그라데이션 경로, 흰색 외곽선, 출발/도착, 진행 방향 애니메이션이 확대·이동 후에도 경로에 붙어 있다.
- [ ] 구간 탭 시 해당 구간만 강조되고 상세 내용은 하단 시트에 표시된다.
- [ ] 직접 그리기에서 물·건물 좌표가 보행 가능 도로로 보정되며, 직전 점 취소가 가능하다.
- [ ] 저장한 커스텀 코스가 목록·상세·대표 설정·삭제에 즉시 반영된다.

## 5. 산책 세션

- [ ] 일반/거리두기/만나기 중 하나를 선택한 뒤 산책을 시작한다.
- [ ] 산책 중 다른 모드로 직접 전환되지 않고 현재 모드의 끄기만 가능하다.
- [ ] 일시정지 중에는 시간·거리·좌표 적재가 증가하지 않는다.
- [ ] 재개 후 실제 이동 경로가 끊기지 않고 누적된다.
- [ ] 화면 잠금 30초, 앱 전환 30초 후 복귀했을 때 세션 상태와 화면이 복구된다.
- [ ] 네트워크를 10초 끊었다 복구해도 중복 산책 생성이나 강제 종료가 발생하지 않는다.
- [ ] 종료 후 이름·대표 코스 여부·동반 반려견이 저장되고 진행 중 세션이 남지 않는다.
- [ ] 같은 계정으로 산책 시작을 빠르게 두 번 눌러도 활성 세션은 하나만 존재한다.

## 6. 거리두기·만나기 실기기 2대 검증

- [ ] 두 기기 모두 거리두기 동의 후 50m/100m/500m 반경 변경이 반영된다.
- [ ] 응답과 화면에 상대방의 정확한 좌표, 사용자 ID, 세션 ID, 정확 거리가 노출되지 않는다.
- [ ] 접근 이벤트가 발생하면 알림과 접근 이력이 한 번만 저장된다.
- [ ] 거리 밖으로 이동한 뒤 재진입했을 때 쿨다운 정책대로 다시 알림된다.
- [ ] 만나기 모드에서는 서로 동의한 사용자끼리만 만남 가능 상태가 보인다.
- [ ] 한쪽이 모드를 끄거나 산책을 종료하면 상대 화면에서 즉시 제거된다.

## 7. 기록·통계·그룹

- [ ] 산책 기록 목록의 실제 지도 썸네일과 상세 경로가 해당 산책 좌표를 가리킨다.
- [ ] 월별 거리·횟수·시간, 2D/3D 발자국, 요일 통계가 같은 원본 기록을 사용한다.
- [ ] 그룹 공개 범위와 참여 방식 조합이 생성·수정 후 유지된다.
- [ ] 영문 소문자 초대 코드는 대문자로 정규화되어 참여된다.
- [ ] 방장과 일반 멤버에게 관리/멤버 UI가 권한에 맞게 보인다.
- [ ] 멤버 내보내기·탈퇴 뒤 해당 멤버가 공유한 코스가 그룹에서 제거된다.
- [ ] 공유 취소·멤버 내보내기·그룹 정보 저장은 서비스 확인 모달을 사용한다.

## 8. 합격 기준

- 치명적 오류, 데이터 유실, 개인정보 노출: 0건
- 주요 시나리오의 4xx/5xx 미처리 화면: 0건
- 동일 동작에 의한 중복 세션·중복 기록: 0건
- Android와 iOS에서 시작→이동→일시정지→재개→종료 시나리오 각각 1회 이상 통과
- 실패 항목은 재현 순서, 기기, 시각, 요청 URL/상태 코드, 화면 캡처를 남긴다.
